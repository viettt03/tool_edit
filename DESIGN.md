# Design System

## Visual Direction

Clean white creator workspace inspired by the supplied reference. A compact sidebar and generous canvas keep navigation familiar. Red is reserved for brand and primary actions, black for hierarchy, and cool gray for structure. No gradients.

## Color Roles

- Canvas / surface: white
- Ink: near-black
- Structure: cool gray
- Accent: vermilion red
- Status: green only for live/success state

## Typography

Use the system sans stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`. Use compact product scale with a stronger display size only for the page title.

## Layout

Fixed left navigation, top utility bar, editorial intro with a line illustration, two-column ingest workspace, then a full-width local library. Collapse navigation and content below tablet width.

## Components

Segmented source switcher, labeled input field, compact limit control, primary action button, inline status panel, progress bar, and file list. States include idle, running, success, and error.

## Motion

Use short 180ms ease-out transitions for focus, hover, progress, and status changes. Respect `prefers-reduced-motion`.
